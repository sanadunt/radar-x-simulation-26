Publish Settings

Data Modules

Enable or disable each schema module and set its MQTT publish topic independently. Disabled modules are never published.

Basic Usage ~200 B/frame
Radar GPS + orientation, all targets with classification, polar coords, geodetic position & velocity. Recommended for most apps.
Frame Metadata ~40 B/frame
Protocol sync wrapper: frame counter, type, timestamp, protocol version, checksum. Always needed for framing.
Radar Location & Status ~200 B/frame
Radar GPS position, orientation, operational state (work mode, fault, scan mode), servo angles, and frequency band.
Radar Configuration ~150 B/change
Silent zones, detection filters (range, speed, height), and autonomous identification settings. Publish on config change.
Radar Health ~300 B/frame
Subarray temperatures, power currents & voltages, fan status, memory health, and firmware versions for diagnostics.
Scan Header ~30 B/frame
Current sweep azimuth & elevation, scan cycle counter, pulse group ID, and total target count. Minimal timing context.
Track Data ~280 B/target
Per-target detailed record: classification, signal quality, polar coordinates, geodetic position, and full ENU velocity vector.
Track Metadata ~50 B/target
Per-target track age, point count, loss count, and UTC timestamp (ISO 8601 + Unix epoch). For track management & prediction.
