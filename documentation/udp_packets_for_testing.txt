PACKET STRUCTURE (All packets follow this format)
================================================================================

Bytes 0-1:   Frame Header (0x55AA) - 2 bytes
Bytes 2-3:   Frame ID - 2 bytes (little-endian)
Bytes 4-7:   Frame Count - 4 bytes (little-endian)
Bytes 8-11:  Content Length - 4 bytes (little-endian)
Byte 12:     Protocol ID - 1 byte
Byte 13:     Protocol Major Version - 1 byte
Byte 14:     Protocol Minor Version - 1 byte
Byte 15:     Checksum - 1 byte
Bytes 16+:   Frame Content (variable length)

Total minimum: 16 bytes (header only)

================================================================================
CHECKSUM CALCULATION  (CORRECTED)
================================================================================

Checksum = sum of ALL bytes EXCEPT:
  - the 2-byte frame_header (bytes 0-1: 55 AA)
  - the checksum byte itself (byte 15)

Formula:
  checksum = (sum(frame[2:15]) + sum(frame[16:])) & 0xFF
           = sum(frame_id[2] + frame_count[4] + content_length[4]
                + protocol_id + protocol_major + protocol_minor
                + all content bytes) & 0xFF

WARNING — COMMON MISTAKE:
  Do NOT sum only from byte 12 (protocol bytes) — this omits
  frame_id, frame_count, content_length and gives wrong results.

Example 1: Header-only (no content)
  frame[2:15] = 00 00 00 00 00 00 00 00 00 00 01 02 0E
  sum = 0x11
  Checksum = 0x11

Example 2: Scan header (20 bytes content, 0 targets, frame_count=1)
  sum(frame[2:15]) = 02+FF+01+00+00+00+14+00+00+00+01+02+0E = 295
  sum(content)     = CD+4C+0E+43+33+33+A3+40+2F+00+00+00+B2+BC+01+00+00+00+00+00 = 1105
  total & 0xFF     = (295 + 1105) & 0xFF = 1400 & 0xFF = 0x78
  Checksum = 0x78

PYTHON SCRIPT TO GENERATE AND SEND PACKETS

import socket
import struct

def create_search_frame(frame_count, azimuth, elevation, targets):
    """Create a search target information frame"""
    
    # Frame header
    frame_header = b'\x55\xAA'
    frame_id = struct.pack('<H', 0xFF02)
    frame_cnt = struct.pack('<I', frame_count)
    
    # Scan header (20 bytes)
    scan_header = struct.pack('<ff', azimuth, elevation)
    scan_header += struct.pack('<II', frame_count, frame_count)
    scan_header += struct.pack('<HH', len(targets), 0)
    
    # Content = scan_header + targets
    content = scan_header
    content_len = len(content)
    content_length = struct.pack('<I', content_len)
    
    # Protocol fields
    protocol_id = b'\x01'
    protocol_major = b'\x02'
    protocol_minor = b'\x0E'
    
    # Calculate checksum
    # IMPORTANT: checksum covers frame[2:] excluding the checksum byte itself,
    # which means: frame_id + frame_count + content_length + proto bytes + content
    checksum_data = frame_id + frame_cnt + content_length \
                    + protocol_id + protocol_major + protocol_minor + content
    checksum = sum(checksum_data) & 0xFF
    
    # Complete frame
    frame = frame_header + frame_id + frame_cnt + content_length
    frame += protocol_id + protocol_major + protocol_minor + bytes([checksum])
    frame += content
    
    return frame

def send_packet(host, port, data):
    """Send UDP packet"""
    sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    sock.sendto(data, (host, port))
    sock.close()

# Example usage
if __name__ == "__main__":
    # Create and send a frame
    packet = create_search_frame(
        frame_count=1,
        azimuth=142.3,
        elevation=5.1,
        targets=[]
    )
    
    print(f"Sending packet ({len(packet)} bytes):")
    print(packet.hex().upper())
    
    send_packet('192.168.1.2', 8000, packet)
